# DX Project LG RouThinQ
## AI 기반 생활 루틴 우선순위 추천 서비스

### 프로젝트 개요
사용자의 일상 루틴을 단순 나열이 아닌,
상황과 행동을 고려해 ‘우선순위’ 를 선정하고
추천하는 서비스를 기획·구현한 프로젝트입니다.

이를 위해 사용자의 상황과 행동에 맞춰 루틴의 우선순위 점수를 예측하고,
결과를 LLM에 전달하여 결과를 사용자에게 설명하는 하이브리드 추천 구조를 설계했습니다.

### 문제 정의
루틴 관리가 사회적 트렌드로 떠오르고 있고, 우리는 많은 사용자가 루틴 형성을 원하지만 이를 꾸준히 실행하지 못한다는 점에 주목했습니다.

### 데이터 
크롤링을 통한 온라인 커뮤니티 데이터 16만건 , 실제 환경을 고려해 설계한 학습용 더미데이터 5,000 건

### 서비스 구조  
루틴 저장 → DB 저장 → 점수 예측 → LLM에 전달 → 사용자 피드백 구조

최우수상 수상
